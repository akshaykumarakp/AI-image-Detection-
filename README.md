# AI vs Real Image Detection Tool

A complete end-to-end Python pipeline to train on an image dataset and detect whether any given image is **Real** or **AI/Fake** (generated by Stable Diffusion, Midjourney, DALL-E, etc.).

---

## 📁 Project Structure

```text
ai-image-detection/
│
├── dataset/                    # Dataset directory
│   ├── train/
│   │   ├── real/               # Put real training images here (.jpg, .png, etc.)
│   │   └── fake/               # Put AI/fake training images here
│   └── val/
│       ├── real/               # Put real validation images here
│       └── fake/               # Put AI/fake validation images here
│
├── dataset.py                  # PyTorch data loader & image preprocessing/augmentations
├── model.py                    # MobileNetV2 Deep Neural Network architecture
├── train.py                    # Training and validation loop (saves best_model.pth)
├── detect.py                   # Image inference & classification script
├── prepare_folders.py          # Helper script to create folder structures
└── requirements.txt            # Required Python packages
```

---

## 🚀 Setup & Installation

### 1. Install Dependencies
Install PyTorch and the required libraries:

```bash
pip install torch torchvision pillow tqdm
```

*(If you have an NVIDIA GPU, install PyTorch with CUDA support from [pytorch.org](https://pytorch.org)).*

### 2. Prepare Folders
Run the setup script if you haven't already:
```bash
python prepare_folders.py
```

---

## 📸 Dataset Preparation

Place your images into the corresponding folders:
- `dataset/train/real/`: Real authentic photos for training.
- `dataset/train/fake/`: AI-generated photos for training.
- `dataset/val/real/`: Real photos for validation.
- `dataset/val/fake/`: AI-generated photos for validation.

> **Tip:** Recommended minimum is 50-100 images per class for basic testing, and 500+ for higher accuracy.

---

## 🏋️ Training the Model

Run the training script:

```bash
python train.py --epochs 10 --batch_size 16 --lr 0.0001
```

### Optional Arguments:
- `--epochs`: Number of training iterations (default: `10`).
- `--batch_size`: Batch size (default: `16`).
- `--data_dir`: Custom path to dataset folder (default: `dataset`).
- `--save_path`: Checkpoint save file name (default: `best_model.pth`).

At each epoch, the model evaluates itself on the validation set and automatically saves the best performing weights to `best_model.pth`.

---

## 🔍 Detecting Real vs AI Images

Once trained, classify any single image with:

```bash
python detect.py --image path/to/your/image.jpg
```
